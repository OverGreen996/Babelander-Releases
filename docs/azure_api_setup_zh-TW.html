Microsoft Azure Translator
從沒有帳號到第一次翻譯

Provider: Microsoft Azure Translator　｜　Document Version: 1.3　｜　Last Reviewed: 2026-09-17

沒有帳號？從下方第 1 步開始；已有帳號可依章節繼續。不想申請 API，可回 Babelander 選「維持全部本機」。

第三方介面、價格、免費額度及政策可能更新。若畫面與本文差異過大，請先停下，以服務最新官方資訊為準。本教學不保證免費，不需要你公開任何 Key。

1 · 先確認 Azure 帳戶與有效訂閱

Step 1 · Microsoft 帳號不等於 Azure 訂閱

你現在在哪裡：尚未進入可建立資源的 Azure Portal。

請這樣做：先到 Azure 免費帳戶 / Free Trial ↗ 登入並確認資格；若不符合試用資格，可自行評估 Pay-As-You-Go 隨用隨付訂閱 ↗，完成後進入 Azure Portal ↗。

完成後應看到：在 Subscriptions／訂閱看到有效訂閱後才建立 Translator。

如果不同／先別做：PAYG 是可產生費用的訂閱，不是免費承諾。已經有有效訂閱不需另購；組織帳號先向管理員確認權限。

Step 2 · 登入出現 Microsoft Services／tenant 錯誤

你現在在哪裡：登入時顯示帳號不存在於租用戶或無權存取，例如 AADSTS50020。

請這樣做：這是帳號／Directory／租用戶登入問題，不是 Translator API Key 錯誤。有有效訂閱：切回正確帳號與 Directory，必要時請管理員確認權限；沒有 Azure 訂閱：依上一步完成帳戶流程，再進 Portal。

完成後應看到：可登入正確 Directory 並看到自己的有效訂閱。

如果不同／先別做：不要反覆重建 Key 或用 API Key 登入。錯誤也可能是登入錯帳號／租用戶，不能一律判定需要購買訂閱。

2 · Free Trial、PAYG 與 F0 要分清楚

Step 3 · 兩種不同層級

你現在在哪裡：在 Azure 訂閱與 Translator 建立頁之間。

請這樣做：Azure Free Trial 是訂閱優惠；Translator F0 是翻譯資源的免費計費層級。PAYG 訂閱也可建立符合資格的 F0。本教學只走 F0。

完成後應看到：你選的是 Translator F0；不是因有試用金就選 S1。

如果不同／先別做：F0 目前文字翻譯為每月 2,000,000 字元，仍以官方為準。F0 不可選時先停下確認資格或既有 F0 資源，不選 S1 當替代步驟。

3 · 找 Microsoft 官方 Translator 並建立

Step 4 · 避開 Marketplace 第三方產品

你現在在哪裡：Azure Portal 頂端搜尋列。

請這樣做：搜尋 Translator，確認 Publisher／發行者是 Microsoft。介面可能顯示 Foundry／Azure AI Foundry，可從 Foundry → 更多服務 → 翻譯工具進入官方 Translator 建立頁。

完成後應看到：頁面是 Microsoft Translator 文字翻譯資源；再按 Create／建立。

如果不同／先別做：不要選 AI Easy Translator、AI Translations、Pig Latin Translator。選單可能變更，可對照 官方建立教學 ↗。

Step 5 · Subscription 與 Resource Group

你現在在哪裡：Create Translator → Basics／基本資料。

請這樣做：Subscription 選自己的有效訂閱。Resource Group 按 Create new／建立新的，名稱可填 Babelander。資源群組只是整理資源的容器。

完成後應看到：訂閱與資源群組兩欄都有有效值。

如果不同／先別做：不要刪除共用資源群組重來；其中可能有其他服務。

Step 6 · Region 與 Global 建立錯誤

你現在在哪裡：Basics 的 Region／位置欄，以及新增 Resource Group 的位置欄。

請這樣做：Region 是 Translator 資源區域；Resource Group 另有儲存管理中繼資料的位置，兩者不能混為一談。若建立時顯示 The location global is not available for resource group，先將資源群組位置設 East Asia。需要區域型 Translator 時可選 East Asia（eastasia）；不可用再查 Southeast Asia 或 Japan East。

完成後應看到：資源群組使用可用的實際地區，Translator 的區域以其資源頁實際顯示為準。

如果不同／先別做：不是所有 Global Translator 都不能用。只修正錯誤所指欄位；不要直接把資源群組位置當成 API Region。

Step 7 · Name 與 Pricing Tier

你現在在哪裡：Basics 下方。

請這樣做：Name 可填 babelander-translator（若重複加自己能辨識的字尾）。Pricing Tier 明確選 Free F0，核對摘要。

完成後應看到：資源名稱可用、計費層級為 F0。

如果不同／先別做：若只有 S1 或其他付費層，不要直接下一步。先確認是否選錯產品、該訂閱已有 F0 或資格／區域受限。

Step 8 · Network／網路

你現在在哪裡：建立流程的 Network 分頁。

請這樣做：一般個人桌面程式需能由目前網路連上公開 API；可選允許所有網路／公開端點存取。若組織要求限制 IP，依管理員規範設定自己的對外 IP。

完成後應看到：Babelander 所在網路可到達 API。

如果不同／先別做：此流程不建立 Private Endpoint／VNet。只允許私人網路可能使家用電腦無法連線。Key 仍必須保密。

Step 9 · Identity 與 Tags

你現在在哪裡：Identity／身分識別及 Tags／標籤分頁（若有）。

請這樣做：本程式用 Key 驗證：System assigned managed identity 保持 Off；不用加入 User assigned identity。Tags 為選填，可留白。

完成後應看到：未額外啟用 Managed Identity，標籤可為空。

如果不同／先別做：Foundry 其他整合可能要求身分識別，與本程式的 Key 文字翻譯流程不同，不照搬其他服務步驟。

Step 10 · Review + Create

你現在在哪裡：Review + Create／檢閱並建立。

請這樣做：確認訂閱、Resource Group、Region、名稱與 F0，再按 Create。部署成功後按 Go to resource／移至資源。

完成後應看到：開啟剛建立的 Translator Overview。

如果不同／先別做：驗證失敗先看哪一欄錯誤，不自行升級付費層解決。

4 · Keys and Endpoint：複製一把 Key

Step 11 · 找到金鑰頁

你現在在哪裡：Translator 左側 Resource Management／資源管理。

請這樣做：開啟 Keys and Endpoint／金鑰與端點。只需複製 Key 1 到 Babelander 的 API Key 欄。

完成後應看到：Key 1、Key 2 為同一資源的兩把有效金鑰。

如果不同／先別做：不需要兩把同時貼上。Key 2 是輪替備用，不是另一份免費額度；勿公開此頁截圖。

5 · Region 與文字翻譯 Endpoint

Step 12 · 填入資源區域代碼

你現在在哪裡：Keys and Endpoint 的 Location／Region。

請這樣做：區域型資源依官方頁複製代碼，例如 East Asia → eastasia、Southeast Asia → southeastasia、Japan East → japaneast。Global Translator 在 Babelander 可留空。

完成後應看到：Region 與 Translator 資源本身一致。

如果不同／先別做：不要填中文地名、資源群組位置或自行猜地區。Region 不一致可能驗證失敗。

Step 13 · 選 Web API 文字翻譯端點

你現在在哪裡：同頁可能列出 Web API、Document Translation 等不同端點。

請這樣做：本程式一般文字翻譯使用 https://api.cognitive.microsofttranslator.com/，Babelander 已預填。不要將 Document Translation 端點直接貼進文字翻譯欄位。

完成後應看到：送出的是 Text Translation /translate 請求。

如果不同／先別做：合法的自訂 Text Translation 端點仍受支援；不是所有自訂網域都只供文件翻譯。若確實使用自訂網域，依 官方驗證與文字端點說明 ↗ 核對用途，不照抄文件端點。

6 · 官方用量與帳務

注意：涉及付款或升級時請先讀完。本程式不會代你開通 Billing、升級、建立資源或設定官方配額；免費資格與價格以官方帳戶為準。

Step 14 · 查看費用及 F0

你現在在哪裡：Azure Portal → Cost Management + Billing／成本管理與帳單。

請這樣做：選自己的訂閱，用 Cost analysis 篩選 Translator。回資源確認 Pricing Tier 仍是 F0，可在 Budgets 設通知。

完成後應看到：可以區分帳單、預算通知與翻譯字元用量。

如果不同／先別做：預算通知不是硬性停止計費；其他資源仍可能收費。PAYG 與 F0 是不同層級。

7 · 本機 1,900,000 字元硬鎖

Step 15 · 每月預留 100,000 字安全緩衝

你現在在哪裡：Babelander 雲端額度總覽。

請這樣做：Azure 分母固定 1,900,000 字元；送出前原子預扣 attempted 字元。預估超過上限便停止，不能按「仍使用 Azure」繞過。

完成後應看到：顯示 LOCAL_SAFETY_LIMIT／本機安全限制；可暫用本機、另一個已設定服務或暫停。永久設定不變。

如果不同／先別做：F0 目前 2,000,000 字額度與本機 1,900,000 字安全線不同。其他程式／裝置、遺失紀錄或共用 Key 的用量不在本機統計內，不能保證整個帳戶零費用。

Step 16 · 核對官方 Metrics

你現在在哪裡：Translator → Monitoring／監視 → Metrics／計量。

請這樣做：查看所選期間的翻譯字元及請求計量，對照資源 F0 限制。

完成後應看到：本機 attempted 含失敗／逾時嘗試，confirmed 只列確認成功；官方可有延遲或不同口徑。

如果不同／先別做：不要把請求次數當作字元數；不反覆更換 Key 規避官方額度。

8 · 本機跨月解鎖與官方限制不同

Step 17 · 本機月界線

你現在在哪裡：Babelander 的下次重置日期（美西時間）。

請這樣做：進入下一個日曆月自動重置本機當月額度，清除因這次安全限制而產生的暫用／暫停，回到原永久設定；跨月後重新啟動也會檢查。

完成後應看到：不需解除安裝，也不改寫永久功能引擎。

如果不同／先別做：本機計數採美西日界線。官方配額／帳單不由此推算；若官方已回覆額度耗盡，仍需核對官方或成功測試，不能僅因本機換月宣告官方已恢復。

回 Babelander · 測試與選擇是兩個步驟

Step 18 · 保留教學，切回程式

你現在在哪裡：你可以讓瀏覽器和 Babelander 並排。

請這樣做：在 Babelander「設定與下載」→「雲端翻譯服務設定（選用）」→「設定 Azure」。填入 Key、Region 與 Endpoint，按「儲存設定」。

完成後應看到：顯示「Key 已加密保存」，回覆引擎仍維持原設定。

如果不同／先別做：教學會在瀏覽器開啟，設定視窗仍保留。不要將其他公司的 Key 填進這個欄位。

Step 19 · 完成前確認，不必先測試

你現在在哪裡：你已填好 Key 與服務設定。

請這樣做：按「完成（確認使用說明，不改變引擎）」。程式先儲存有效設定，再顯示 Azure 獨立說明，閱讀並勾選了解後按同意。即使已測試，這個完成按鈕仍會顯示確認。

完成後應看到：服務會列入可選清單；這個步驟不傳送測試文字、不切換永久引擎。

如果不同／先別做：取消會保留設定視窗，不會新增同意。若先儲存再用 X 關閉，外層「完成」也會補問已設定但未同意的服務。未設定 Key 可直接關閉，不必申請雲端。

Step 20 · 選用：主動測試一次

你現在在哪裡：想確認 Key 與端點可連線時，重新開啟該服務設定。

請這樣做：按「測試連線（僅傳送『你好』，2 字）」。尚未同意使用說明時會先詢問；已同意則直接測試。

完成後應看到：成功顯示連線成功及英文 Hello 類型結果；只有固定測試文字送出。

如果不同／先別做：測試可略過，不再是讓服務出現在清單的必要步驟。測試會使用服務額度；失敗時看下面的排查，勿連續狂按。

Step 21 · 另行選擇各功能引擎

你現在在哪裡：關閉這個服務設定視窗，回「功能引擎與雲端設定」。

請這樣做：只有當你真的想使用 Azure 時，才在「中文回覆」下拉選 Azure。

完成後應看到：只有明確選用的功能會傳送文字；字幕／卡片選用前會再確認文字傳送範圍。

如果不同／先別做：儲存／測試成功不會自動選取。字幕、裝備、任務可獨立選用；聊天室來訊永遠本機。

Step 22 · 正常結果與待核對

你現在在哪裡：從聊天控制鈕開啟中翻英回覆小窗。

請這樣做：輸入一則中文草稿，按翻譯。檢查結果來源及提醒；若顯示待核對，確認英文後才按複製。

完成後應看到：正常結果僅複製到剪貼簿，由你自行回遊戲貼上並送出。

如果不同／先別做：名字、數字或保護標記異常會拒收；即使英文流暢也不保證語意完全正確。網路／逾時不會自動反覆重試。

故障排除 · Key／401

Step 23 · 驗證失敗

你現在在哪裡：程式顯示 Key 無效或 HTTP 401 類型錯誤。

請這樣做：回本頁 Key 章節確認服務、帳戶和有效 Key，重新複製，不含額外空白；Azure 要一起核對 Region，DeepL 核對 API Plan／Endpoint。

完成後應看到：儲存後手動再測一次。

如果不同／先別做：不要將錯誤頁上的私人帳戶、Key 或帳單分享給他人。仍失敗可檢查官方狀態與 Key 是否已撤銷。

故障排除 · 拒絕存取／403

Step 24 · 逐項找原因

你現在在哪裡：程式顯示拒絕存取。

請這樣做：Google：依序確認 API 已啟用、Key 限制、Billing 和 Quota。Azure：確認資源／訂閱有效、Region、網路限制及方案額度。DeepL：確認 API Key 與 API Endpoint 的方案一致。

完成後應看到：修正實際原因後再測一次，不必一次更改所有設定。

如果不同／先別做：403 並不一定是付款問題。不要只因看到這個代碼就升級方案或移除所有安全限制。只看與本頁 Provider 對應的項目。

故障排除 · 太頻繁／429、方案額度

Step 25 · 暫停請求

你現在在哪裡：429 通常表示流量／配額限制；Azure 額度錯誤或 DeepL 456 也要查看方案用量。

請這樣做：等候後手動重試，或明確將 Reply 改成本機。到本頁 Quota 章節檢查官方限制，別增加重試頻率。

完成後應看到：若選了本機備援，結果會清楚標示；永久引擎不會因此自動改變。

如果不同／先別做：額度限制時可在提示中暫用本機、另一家已設定服務或暫停；未設定服務需先完成獨立設定和同意。不能繼續送往被鎖服務，也不改寫永久引擎。

停用 · 先停止新的雲端請求

Step 26 · 只停用 Babelander 的此服務

你現在在哪裡：在 Azure 設定視窗。

請這樣做：按「停用此服務」。使用此服務的功能會暫停；Key 暫時保留，重新使用須再次確認。

完成後應看到：後續不再使用此服務；取消中的結果不會複製。

如果不同／先別做：已經傳出去的內容不能撤回。停用本機程式不等於關閉官方服務或取消方案。

刪除或更換 Key（Rotate）

Step 27 · 先清除本機 Key

你現在在哪裡：在 Azure 設定視窗。

請這樣做：按「刪除本機 Key」。

完成後應看到：加密 Key 副本被刪除，用量紀錄仍保留。

如果不同／先別做：如果 Key 外洩，還要完成下面的官方撤銷；只刪本機不能讓別人手中的 Key 失效。

Step 28 · 在官方撤銷或更換

你現在在哪裡：Azure 的官方帳戶管理頁。

請這樣做：在同一 Translator Resource → Keys and Endpoint，使用 Key 1／Key 2 更換：先把程式改用另一把有效 Key 並測試，再重新產生舊 Key。重新產生會使舊值失效。不再需要服務時，可在該資源 Overview 按 Delete，仔細確認只刪這份 Translator。

完成後應看到：舊 Key 不再能呼叫服務；新 Key 若需要使用，回 Babelander 儲存並測試。

如果不同／先別做：刪除資源群組會連其他資源一起影響；不應代替刪一份 Translator。刪資源不會抹去已產生的帳單，也不代表整個 Azure 訂閱已取消。

隱私：聊天室固定本機，各功能獨立選擇

只有明確選用 Microsoft Azure Translator 的功能會傳送待翻譯文字。字幕傳送框選 OCR 文字；裝備／任務傳送規則未能完成的文字；Reply 傳送當前主動提交的中文。圖片、聊天室來訊、歷史與完整詞庫不會上傳。儲存 Key 本身不會啟用任何雲端功能。Key 使用 Windows 使用者加密；搬到另一台電腦或帳號需要重新輸入。設定、儲存或測試服務不會自動改變功能引擎。

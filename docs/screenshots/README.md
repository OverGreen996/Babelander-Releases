# Screenshot provenance

These images show Babelander v1.4.3 production Qt widgets with synthetic demonstration text. They are not screenshots of a commercial game and do not claim a live OCR/model benchmark.

- main-window.png, subtitle-overlay.png, equipment-card.png: rendered directly from the application widgets in an isolated documentation session; no live capture, model request, cloud API call, or user configuration was used.
- chat-overlay.png, reply-window.png: captured during the packaged v1.4.3 UI self-test with sample messages.
- UI artwork uses the project assets documented in ../../ASSET_PROVENANCE.md.

The public images contain no API keys, personal conversations, desktop paths, or third-party game screenshots. Application code and the documentation capture script are not included in this public repository.

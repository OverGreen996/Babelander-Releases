1 · 從 Google 帳號開始

Step 1 · 我有帳號嗎？

你現在在哪裡：你現在在這份離線教學。Gmail 帳號通常就是 Google 帳號。

請這樣做：有帳號：登入 Google ↗。沒有帳號：建立 Google 帳號 ↗，照官方畫面完成驗證。

完成後應看到：登入後應看到自己的帳戶頭像。建立一般 Google 帳號不等於建立付費 Cloud 專案。

如果不同／先別做：不要把密碼輸入 Babelander。若使用學校或公司帳號，Cloud 可能被管理員限制，可洽管理員確認。

Step 2 · 進入 Google Cloud

你現在在哪裡：保持剛才的 Google 帳號登入。

請這樣做：開啟 Google Cloud Console ↗，完成國家／地區與服務條款畫面。

完成後應看到：你會進入雲端控制台，頂部有搜尋列與專案選擇器。

如果不同／先別做：畫面要求建立 Billing 時，先閱讀本頁「費用與試用」再決定。不要把開始試用當成保證永久免費。

2 · 這項選用功能是什麼

Step 3 · 先認識名詞

你現在在哪裡：你準備設定 Google 的文字翻譯服務。

請這樣做：API 是讓程式向服務請求翻譯的入口；API Key 是辨認你帳戶／專案的祕密通行碼。Project 是放置 API、配額與帳務關聯的專案。

完成後應看到：不設定也能選本機 Qwen。字幕、裝備、任務與中文 Reply 可獨立選用 Google，聊天室來訊仍固定本機。

如果不同／先別做：這不是 Google Translate 網站帳號登入，也不是 Gemini／AI Studio 金鑰教學。不要建立其他 AI 模型或服務。

3 · 建立並選對專案

Step 4 · 建立自己的專案

你現在在哪裡：在 Cloud Console 頂部，找到目前專案名稱或「選取專案 / Select a project」。

請這樣做：點選專案選擇器，再按「新增專案 / New Project」。

完成後應看到：出現專案名稱欄。

如果不同／先別做：若看不到新增按鈕，先確認登入帳號有建立專案權限。不要刪除既有公司專案。

Step 5 · 命名並完成

你現在在哪裡：你應在「新增專案」頁。

請這樣做：名稱填 Babelander Translate；組織／位置依帳號可用選項，個人帳號可選沒有組織。按「建立 / Create」。

完成後應看到：等待建立完成，再從頂部專案選擇器選 Babelander Translate。

如果不同／先別做：專案 ID 可能自動加上數字，正常。以頁面頂部專案名稱確認後才繼續。

Step 6 · 找到翻譯 API

你現在在哪裡：頂部已選 Babelander Translate。

請這樣做：在搜尋列輸入 Cloud Translation API，選 Google 提供的同名結果。

完成後應看到：頁面顯示 Cloud Translation API 與「啟用 / Enable」或「管理 / Manage」。

如果不同／先別做：不要選 Cloud Vision、Speech、Gemini 或其他翻譯產品。若結果不同，使用 官方 Translation API 頁 ↗ 並再次確認專案。

Step 7 · 啟用服務

你現在在哪裡：停留在 Cloud Translation API 頁。

請這樣做：按「啟用 / Enable」。已顯示「管理 / Manage」表示通常已啟用，進入管理頁即可。

完成後應看到：API 已加入這個專案。

如果不同／先別做：若要求帳務，閱讀下方 Billing 章節。啟用 API 不等於已設定配額，先不要大量翻譯。

4 · 建立並限制 API Key

Step 8 · 打開憑證頁

你現在在哪裡：你在 Cloud Console，頂部仍是 Babelander Translate。

請這樣做：左上三條線選單 →「API 和服務 / APIs & Services」→「憑證 / Credentials」。也可按 官方憑證頁 ↗。

完成後應看到：看到憑證清單與「建立憑證 / Create credentials」。

如果不同／先別做：清單為空是正常的。如果看不到此選單，確認不是 Billing 專用頁且專案正確。

Step 9 · 建立 Key

你現在在哪裡：在憑證頁。

請這樣做：按「建立憑證 / Create credentials」→「API 金鑰 / API key」。名稱可填 Babelander Reply；若同頁可設定限制，按下一步的方式限制後建立。

完成後應看到：建立完成會顯示一串 Key，之後可由此頁管理。

如果不同／先別做：本程式使用一般 API Key，不需下載 Service Account JSON，也不要勾選綁定服務帳戶的進階選項。此頁會有祕密資料，不要截圖分享。

Step 10 · 只允許 Translation

你現在在哪裡：點剛建立的 Key 名稱，開啟編輯頁。

請這樣做：在「API 限制 / API restrictions」選「限制金鑰 / Restrict key」，清單只勾 Cloud Translation API，按「儲存 / Save」。

完成後應看到：Key 的限制清單應只剩翻譯 API。

如果不同／先別做：找不到 Cloud Translation 時，返回上一章確認此專案已啟用 API，再重新整理。不要選「全部 API」省略限制。

Step 11 · 桌面程式的應用程式限制

你現在在哪裡：仍在同一個 Key 編輯頁的「應用程式限制 / Application restrictions」。

請這樣做：Babelander 是 Windows 桌面程式，網站 HTTP referrer／Android／iOS 限制不適用。沒有固定對外 IP 的個人使用者可保持此項 None，但務必保留上一步的 API 限制。

完成後應看到：程式可用 Key 呼叫 Translation。

如果不同／先別做：若你熟悉且有固定對外 IP，可限制該 IP；換網路可能失敗。這不是建議公開 Key，API 限制仍不能阻止取得 Key 的人消耗翻譯額度。

5 · 費用、Billing 與 Free Trial

注意：涉及付款或升級時請先讀完。本程式不會代你開通 Billing、升級、建立資源或設定官方配額；免費資格與價格以官方帳戶為準。

Step 12 · 看清楚帳務狀態

你現在在哪裡：Billing 就是雲端帳務；可能與付款方式、試用額度和專案連結。

請這樣做：打開 Google Cloud Billing ↗，選你的 Billing account，再看「總覽 / Overview」及專案連結狀態。

完成後應看到：你應能辨認帳戶是試用還是已啟用付費，以及 Babelander Translate 是否連到此帳戶。

如果不同／先別做：要求信用卡、升級或付款資料時，先看官方 Translation 定價 ↗。免費額度可能變更，超過可能計費，不要只依賴本機估算。

Step 13 · 注意：試用限制不是按 Cancel Trial 解決

你現在在哪裡：若 Quota 無法編輯，先查看畫面是否寫權限不足、服務限制或 Free Trial 限制。

請這樣做：先確認原因。只有當你願意承擔付費且官方要求時，才考慮 Billing Overview 的「Upgrade／Activate／升級／啟用完整帳戶」。不要按 Cancel Trial 來解除配額限制。

完成後應看到：升級可能使帳戶具備實際付費能力；完成後先回本頁 Quota 章節設額度，再開始使用。

如果不同／先別做：不要以為升級等於免費。也不是所有配額問題都能靠升級解決；不願付費可留在本機。詳見 官方試用 FAQ ↗。

Step 14 · 查看費用與設定通知

你現在在哪裡：在 Billing 帳戶頁。

請這樣做：開啟「報表 / Reports」或「費用明細 / Cost table」，篩選你的專案；在「預算與快訊 / Budgets & alerts」建立適合的通知金額。

完成後應看到：之後可檢視實際帳單與收到額度提醒。

如果不同／先別做：只有通知的預算不會自動停用付費使用。若官方另提供 spend cap 功能，先確認是否支援你的服務，不把它與通知型預算混為一談。

6 · 先設每日字元額度

Step 15 · 打開配額頁

你現在在哪裡：Quota 就是服務允許的使用量上限，和 API Key 不是同一個東西。

請這樣做：在 Console 搜尋「Quotas & System Limits／配額與系統限制」，或按 官方配額頁 ↗；頂部選你的專案。

完成後應看到：出現服務與配額清單。

如果不同／先別做：清單很多時篩選 Cloud Translation API，不要改其他服務配額。

Step 16 · 找到按天計算的字元欄位

你現在在哪裡：在 Translation 配額清單。

請這樣做：尋找「Characters sent to general model per project per day (v2 and v3)／一般模型每個專案每日字元數」，勾選該列後按「Edit quotas／編輯配額」。

完成後應看到：右側或對話框會顯示目前與新的額度。

如果不同／先別做：不要把 per minute（每分鐘）、requests（請求次數）、LLM 或 document 項目當成每日一般模型字元。

Step 17 · 設定保守上限並確認生效

你現在在哪裡：你在每日字元配額編輯頁。

請這樣做：建議先填 15000，按提交／儲存。回清單確認值已更新且沒有待處理狀態。

完成後應看到：設定成功後，Google 會依專案額度處理；每日配額以美西時間重置。

如果不同／先別做：變更可能最多需 24 小時。若拒絕編輯或數字沒變，先停止雲端使用並回 Billing／權限排查；不要假設已成功。

Step 18 · 理解本機計數的界線

你現在在哪裡：Babelander 會顯示本機估算。

請這樣做：本機 Google 上限為 450,000 字／美西月份，包含術語標記、空白及失敗嘗試；用它作輔助，並查看 Cloud Console 的實際使用量。

完成後應看到：完整句詞庫或快取命中不會送 API。

如果不同／先別做：同一 Key 被其他電腦或程式使用不在本機統計內；重新安裝也不會重置 Google 帳單。不要建立新 Key 或帳號迴避配額。

7 · Google 不需要填 Endpoint

Step 19 · 使用固定 NMT 服務

你現在在哪裡：本程式固定使用 Google Basic v2 NMT。

請這樣做：在 Babelander 只填 Google API Key；不填服務網址、不切換到 LLM。

完成後應看到：請求只會送到官方 translation.googleapis.com。

如果不同／先別做：如果網站提供的是 Gemini Key 教學，請回 Cloud Translation 步驟。

回 Babelander · 測試與選擇是兩個步驟

Step 20 · 保留教學，切回程式

你現在在哪裡：你可以讓瀏覽器和 Babelander 並排。

請這樣做：在 Babelander「設定與下載」→「雲端翻譯服務設定（選用）」→「設定 Google」。填入 API Key，按「儲存設定」。

完成後應看到：顯示「Key 已加密保存」，回覆引擎仍維持原設定。

如果不同／先別做：教學會在瀏覽器開啟，設定視窗仍保留。不要將其他公司的 Key 填進這個欄位。

Step 21 · 完成前確認，不必先測試

你現在在哪裡：你已填好 Key 與服務設定。

請這樣做：按「完成（確認使用說明，不改變引擎）」。程式先儲存有效設定，再顯示 Google 獨立說明，閱讀並勾選了解後按同意。即使已測試，這個完成按鈕仍會顯示確認。

完成後應看到：服務會列入可選清單；這個步驟不傳送測試文字、不切換永久引擎。

如果不同／先別做：取消會保留設定視窗，不會新增同意。若先儲存再用 X 關閉，外層「完成」也會補問已設定但未同意的服務。未設定 Key 可直接關閉，不必申請雲端。

Step 22 · 選用：主動測試一次

你現在在哪裡：想確認 Key 與端點可連線時，重新開啟該服務設定。

請這樣做：按「測試連線（僅傳送『你好』，2 字）」。尚未同意使用說明時會先詢問；已同意則直接測試。

完成後應看到：成功顯示連線成功及英文 Hello 類型結果；只有固定測試文字送出。

如果不同／先別做：測試可略過，不再是讓服務出現在清單的必要步驟。測試會使用服務額度；失敗時看下面的排查，勿連續狂按。

Step 23 · 另行選擇各功能引擎

你現在在哪裡：關閉這個服務設定視窗，回「功能引擎與雲端設定」。

請這樣做：只有當你真的想使用 Google 時，才在「中文回覆」下拉選 Google。

完成後應看到：只有明確選用的功能會傳送文字；字幕／卡片選用前會再確認文字傳送範圍。

如果不同／先別做：儲存／測試成功不會自動選取。字幕、裝備、任務可獨立選用；聊天室來訊永遠本機。

Step 24 · 正常結果與待核對

你現在在哪裡：從聊天控制鈕開啟中翻英回覆小窗。

請這樣做：輸入一則中文草稿，按翻譯。檢查結果來源及提醒；若顯示待核對，確認英文後才按複製。

完成後應看到：正常結果僅複製到剪貼簿，由你自行回遊戲貼上並送出。

如果不同／先別做：名字、數字或保護標記異常會拒收；即使英文流暢也不保證語意完全正確。網路／逾時不會自動反覆重試。

故障排除 · Key／401

Step 25 · 驗證失敗

你現在在哪裡：程式顯示 Key 無效或 HTTP 401 類型錯誤。

請這樣做：回本頁 Key 章節確認服務、帳戶和有效 Key，重新複製，不含額外空白；Azure 要一起核對 Region，DeepL 核對 API Plan／Endpoint。

完成後應看到：儲存後手動再測一次。

如果不同／先別做：不要將錯誤頁上的私人帳戶、Key 或帳單分享給他人。仍失敗可檢查官方狀態與 Key 是否已撤銷。

故障排除 · 拒絕存取／403

Step 26 · 逐項找原因

你現在在哪裡：程式顯示拒絕存取。

請這樣做：Google：依序確認 API 已啟用、Key 限制、Billing 和 Quota。Azure：確認資源／訂閱有效、Region、網路限制及方案額度。DeepL：確認 API Key 與 API Endpoint 的方案一致。

完成後應看到：修正實際原因後再測一次，不必一次更改所有設定。

如果不同／先別做：403 並不一定是付款問題。不要只因看到這個代碼就升級方案或移除所有安全限制。只看與本頁 Provider 對應的項目。

故障排除 · 太頻繁／429、方案額度

Step 27 · 暫停請求

你現在在哪裡：429 通常表示流量／配額限制；Azure 額度錯誤或 DeepL 456 也要查看方案用量。

請這樣做：等候後手動重試，或明確將 Reply 改成本機。到本頁 Quota 章節檢查官方限制，別增加重試頻率。

完成後應看到：若選了本機備援，結果會清楚標示；永久引擎不會因此自動改變。

如果不同／先別做：額度限制時可在提示中暫用本機、另一家已設定服務或暫停；未設定服務需先完成獨立設定和同意。不能繼續送往被鎖服務，也不改寫永久引擎。

停用 · 先停止新的雲端請求

Step 28 · 只停用 Babelander 的此服務

你現在在哪裡：在 Google 設定視窗。

請這樣做：按「停用此服務」。使用此服務的功能會暫停；Key 暫時保留，重新使用須再次確認。

完成後應看到：後續不再使用此服務；取消中的結果不會複製。

如果不同／先別做：已經傳出去的內容不能撤回。停用本機程式不等於關閉官方服務或取消方案。

刪除或更換 Key（Rotate）

Step 29 · 先清除本機 Key

你現在在哪裡：在 Google 設定視窗。

請這樣做：按「刪除本機 Key」。

完成後應看到：加密 Key 副本被刪除，用量紀錄仍保留。

如果不同／先別做：如果 Key 外洩，還要完成下面的官方撤銷；只刪本機不能讓別人手中的 Key 失效。

Step 30 · 在官方撤銷或更換

你現在在哪裡：Google 的官方帳戶管理頁。

請這樣做：在 Cloud Console → API 和服務 → 憑證，選該 Key，使用頁面提供的刪除／撤銷選項並確認。需要換 Key 時先建立受限制的新 Key、更新程式並測試，再刪舊 Key；若已外洩，應優先撤銷舊 Key。

完成後應看到：舊 Key 不再能呼叫服務；新 Key 若需要使用，回 Babelander 儲存並測試。

如果不同／先別做：不要刪除整個共用專案來代替刪一把 Key。查看 Billing 確認過去使用仍可能已產生費用。

隱私：聊天室固定本機，各功能獨立選擇

只有明確選用 Google Cloud Translation 的功能會傳送待翻譯文字。字幕傳送框選 OCR 文字；裝備／任務傳送規則未能完成的文字；Reply 傳送當前主動提交的中文。圖片、聊天室來訊、歷史與完整詞庫不會上傳。儲存 Key 本身不會啟用任何雲端功能。Key 使用 Windows 使用者加密；搬到另一台電腦或帳號需要重新輸入。設定、儲存或測試服務不會自動改變功能引擎。

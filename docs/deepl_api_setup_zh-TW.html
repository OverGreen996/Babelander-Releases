1 · 帳號與 API 方案

Step 1 · 沒有 DeepL 帳號

你現在在哪裡：你目前只需要瀏覽器，不用寫程式。

請這樣做：開啟 DeepL 帳戶登入 ↗；沒有帳號請從 官方 API 方案頁 ↗ 選適合方案並依畫面註冊／驗證 Email。

完成後應看到：登入後可以進入 Account／帳戶。

如果不同／先別做：只開啟免費翻譯網站不代表已取得 API 資格。註冊要求付款資料時，先閱讀本頁費用章節。

Step 2 · 確認是 API 訂閱

你現在在哪裡：在帳戶的 Plan／Subscription／方案頁。

請這樣做：確認方案名稱含 API／Developer，並查看當前額度、限制、費用與續約條件。

完成後應看到：你能在帳戶中找到 API 相關分頁。

如果不同／先別做：一般網站翻譯器的付費會員不一定含 API。找不到 API Keys 時先確認方案，不要重複付費訂閱多個方案。

2 · DeepL API 是什麼

Step 3 · 認識 API Key

你現在在哪裡：API 是供程式請求翻譯的入口；Key 是你的祕密通行碼。

請這樣做：Babelander 的字幕、裝備、任務與中文 Reply 可各自選用 DeepL；你仍可完全使用本機 Qwen。

完成後應看到：不必向 Babelander 輸入 DeepL 登入密碼。

如果不同／先別做：來訊監測固定本機；不會因儲存 DeepL Key 上傳整段聊天室內容。

3 · 找到並建立 Authentication Key

Step 4 · 打開 Key 頁

你現在在哪裡：登入 DeepL Account ↗ 後。

請這樣做：在帳戶分頁找「API Keys & Limits／API 金鑰與限制」，部分介面可能顯示「API Keys」。

完成後應看到：看到 Key 清單與建立按鈕。

如果不同／先別做：沒有這個分頁時，回 API Plan 確認帳戶確實提供 API，不要到一般翻譯器設定找。

Step 5 · 新增 Key

你現在在哪裡：在 API Keys & Limits 頁。

請這樣做：按 Create key／建立金鑰，名稱可填 Babelander Reply，再按確認。

完成後應看到：清單中出現新 Key；可用複製按鈕取得完整值。

如果不同／先別做：可建立數量依方案不同；達上限時先辨認現有 Key 用途，不要誤撤銷其他程式在用的 Key。

Step 6 · 複製到程式

你現在在哪裡：在剛建立的 Key 旁。

請這樣做：按複製圖示，稍後貼到 Babelander DeepL 的 API Key 欄。

完成後應看到：程式會遮蔽顯示並在本機加密保存。

如果不同／先別做：不要把 Key 貼到搜尋引擎、公開 Issue 或教學圖片。教學範例 YOUR_API_KEY 是假值，不能用來測試。

4 · API 端點與方案一致

Step 7 · 保持自動辨認或依官方方案選擇

你現在在哪裡：在 Babelander DeepL 設定的「API Endpoint」。

請這樣做：初次可保持「依 Key 自動選擇」。傳統 API Free 的 :fx 結尾 Key 使用 api-free.deepl.com；其他 Key 預設 api.deepl.com。若你的方案明確指定不同，依官方說明在支援的選項中選擇。

完成後應看到：程式只會送往所選的 DeepL 官方網域。

如果不同／先別做：Free、Developer、Growth、Pro 等方案可能改變；不要僅憑名稱假設免費字數。本版僅支援列出的兩個全域端點，其他區域端點先不要填進任意網址。

5 · 先看費用與目前方案

注意：涉及付款或升級時請先讀完。本程式不會代你開通 Billing、升級、建立資源或設定官方配額；免費資格與價格以官方帳戶為準。

Step 8 · 查看 Plan 與 Billing

你現在在哪裡：在 DeepL Account。

請這樣做：找到 Plan／Subscription 與 Billing／Invoices（帳單／發票），確認方案、續約、付款和用量計費條件。升級前看 官方 API 定價與方案 ↗。

完成後應看到：你知道什麼情況會增加費用，才開始大量使用。

如果不同／先別做：不把「免費」寫成永久固定額度。不同帳戶可能有不同方案與試用條件，以帳戶實際顯示為準。

Step 9 · 需要升級時先停一下

你現在在哪裡：當頁面提示升級或增加消費上限。

請這樣做：先確認新方案月費、用量費與生效時間，再自行決定；不願升級可繼續本機模式。

完成後應看到：Babelander 不會代為購買或升級。

如果不同／先別做：不要為讓測試成功就直接按購買。網站會員與 API 方案仍需分清楚。

6 · 設定 Key 限制並看 Usage

Step 10 · 設定官方可用的限制

你現在在哪裡：回 API Keys & Limits，找到 Babelander Reply 這把 Key。

請這樣做：查看 Usage limit／使用上限選項，依自己方案設定保守的字元限制；如果帳戶有 Subscription Cost Control，也一起確認。

完成後應看到：儲存後頁面應顯示新限制，請確認生效。

如果不同／先別做：若頁面沒有此功能，不代表無限免費；查看方案說明，必要時停止雲端使用。不自動套用其他帳戶的範例額度。

Step 11 · 讀懂 Usage

你現在在哪裡：在同頁 Key 用量或帳戶 Usage／用量分頁。

請這樣做：確認統計期間、已用量與剩餘額度，再對照方案條件。

完成後應看到：能分辨官方目前計費期間與 Babelander 自訂重置日的本機估算。

如果不同／先別做：本機每期字元上限由你設定；500,000 只是示例，不是 DeepL 官方免費承諾。官方 456 額度錯誤需先查限制，不應反覆重試或換 Key 規避。

DeepL 方案與額度週期

Step 12 · 確認實際 API 方案

你現在在哪裡：DeepL 帳戶的 API Plan 與 Usage 頁。

請這樣做：在 Babelander DeepL 設定中選擇官方顯示的方案。Developer 總額度不按月重置；Growth 月繳按實際計費週期，年繳按年度週期。舊 API Free 的月額度是另一種方案。

完成後應看到：額度限制會分成 PLAN_LIMIT、MONTHLY_LIMIT 或 BILLING_PERIOD_LIMIT。

如果不同／先別做：未知方案不假設每月一號恢復。DeepL 用量與計費 ↗

Step 13 · 讀取官方週期

你現在在哪裡：DeepL 設定視窗。

請這樣做：按讀取官方用量；支援的帳戶可顯示 start_time / end_time 與官方已用／限額。

完成後應看到：不會改變 Key、方案、計費或功能設定。

如果不同／先別做：官方用量可能延遲。本機 attempted / confirmed 與官方帳單不同；無週期欄位時不推測重置日期。

手動同步官方用量基準

Step 14 · 何時需要同步

你現在在哪裡：DeepL 設定視窗；同一 Key 曾在別的軟體或裝置使用。

請這樣做：按「同步官方用量基準（手動）」。只讀 GET /v2/usage，不翻譯文字，也不改變官方限額。

完成後應看到：保存官方用量、上限、可取得的週期與同步時間。用官方基準加同步後本機新增嘗試，與本機本期嘗試取較大值，作為安全估算。

如果不同／先別做：官方數字較小不會下修本機 attempted 或同一期安全估算；查詢期間新請求也計入。沒有背景輪詢。

Step 15 · 日期缺少或週期已結束

你現在在哪裡：查看同步結果的官方起訖時間。

請這樣做：官方有日期時，基準跨本機重置日保留；到期後手動同步確認下一期。沒有日期則依你設定的本機 UTC billing day，未設定則不自行清零。

完成後應看到：只有已驗證的新官方週期可退休舊基準；同步不解除官方錯誤或改選功能引擎。

如果不同／先別做：部分方案只回傳用量與上限；官方資料可能延遲，其他裝置的後續用量也無法得知。官方 usage 說明 ↗

DeepL 本機上限與每月重置日

Step 16 · 依帳戶填日期，不猜每月一號

你現在在哪裡：DeepL 帳戶 → Subscription／訂閱 → Usage period／使用期間。

請這樣做：例如期間顯示 9 月 17 日至 10 月 17 日，在 Babelander 每月重置日選 17；只選 1–31，不需年或月。每期字元上限依自己的方案設定，例如 500,000。

完成後應看到：儲存後資源條顯示自己的分母、每月 17 日及下一次重置日期（DeepL 獨立 UTC 日界線；舊版首期不提早重置）。

如果不同／先別做：未確認重置日就保持未設定，本機不自動清零。官方精確時區／期間仍以帳戶為準。Developer 總額度與年繳方案不採月重置。

Step 17 · 31 日與短月份

你現在在哪裡：你的每月重置日是 31。

請這樣做：本機依日曆計算：1/31 → 2/28（閏年 2/29）→ 3/31 → 4/30，始終保留原本 31 日設定。

完成後應看到：不會用固定加 30 天造成日期漂移。

如果不同／先別做：更改重置日或方案不會立即補滿額度；已用量保留，未結束週期不提前重置。

Step 18 · 到達上限的行為

你現在在哪裡：本機安全估算（含手動同步官方基準）已達或下一請求將超過限額。

請這樣做：程式在 HTTP 前停止並顯示 LOCAL_SAFETY_LIMIT。選擇暫用本機、另一個已設定服務或暫停；不能繼續送往被鎖服務。

完成後應看到：沒有官方日期基準時依設定 UTC 週期重置；有官方日期則到期要求手動同步下一期。永久設定保持原值。

如果不同／先別做：403 是驗證問題，429 是限流，456 是官方方案／期間額度，5xx 是暫時服務錯誤；官方 456 不會因本機日期到期就被清除。

回 Babelander · 測試與選擇是兩個步驟

Step 19 · 保留教學，切回程式

你現在在哪裡：你可以讓瀏覽器和 Babelander 並排。

請這樣做：在 Babelander「設定與下載」→「雲端翻譯服務設定（選用）」→「設定 DeepL」。填入 Key、API Endpoint、每期字元上限與每月重置日，按「儲存設定」。

完成後應看到：顯示「Key 已加密保存」，回覆引擎仍維持原設定。

如果不同／先別做：教學會在瀏覽器開啟，設定視窗仍保留。不要將其他公司的 Key 填進這個欄位。

Step 20 · 完成前確認，不必先測試

你現在在哪裡：你已填好 Key 與服務設定。

請這樣做：按「完成（確認使用說明，不改變引擎）」。程式先儲存有效設定，再顯示 DeepL 獨立說明，閱讀並勾選了解後按同意。即使已測試，這個完成按鈕仍會顯示確認。

完成後應看到：服務會列入可選清單；這個步驟不傳送測試文字、不切換永久引擎。

如果不同／先別做：取消會保留設定視窗，不會新增同意。若先儲存再用 X 關閉，外層「完成」也會補問已設定但未同意的服務。未設定 Key 可直接關閉，不必申請雲端。

Step 21 · 選用：主動測試一次

你現在在哪裡：想確認 Key 與端點可連線時，重新開啟該服務設定。

請這樣做：按「測試連線（僅傳送『你好』，2 字）」。尚未同意使用說明時會先詢問；已同意則直接測試。

完成後應看到：成功顯示連線成功及英文 Hello 類型結果；只有固定測試文字送出。

如果不同／先別做：測試可略過，不再是讓服務出現在清單的必要步驟。測試會使用服務額度；失敗時看下面的排查，勿連續狂按。

Step 22 · 另行選擇各功能引擎

你現在在哪裡：關閉這個服務設定視窗，回「功能引擎與雲端設定」。

請這樣做：只有當你真的想使用 DeepL 時，才在「中文回覆」下拉選 DeepL。

完成後應看到：只有明確選用的功能會傳送文字；字幕／卡片選用前會再確認文字傳送範圍。

如果不同／先別做：儲存／測試成功不會自動選取。字幕、裝備、任務可獨立選用；聊天室來訊永遠本機。

Step 23 · 正常結果與待核對

你現在在哪裡：從聊天控制鈕開啟中翻英回覆小窗。

請這樣做：輸入一則中文草稿，按翻譯。檢查結果來源及提醒；若顯示待核對，確認英文後才按複製。

完成後應看到：正常結果僅複製到剪貼簿，由你自行回遊戲貼上並送出。

如果不同／先別做：名字、數字或保護標記異常會拒收；即使英文流暢也不保證語意完全正確。網路／逾時不會自動反覆重試。

故障排除 · Key／401

Step 24 · 驗證失敗

你現在在哪裡：程式顯示 Key 無效或 HTTP 401 類型錯誤。

請這樣做：回本頁 Key 章節確認服務、帳戶和有效 Key，重新複製，不含額外空白；Azure 要一起核對 Region，DeepL 核對 API Plan／Endpoint。

完成後應看到：儲存後手動再測一次。

如果不同／先別做：不要將錯誤頁上的私人帳戶、Key 或帳單分享給他人。仍失敗可檢查官方狀態與 Key 是否已撤銷。

故障排除 · 拒絕存取／403

Step 25 · 逐項找原因

你現在在哪裡：程式顯示拒絕存取。

請這樣做：Google：依序確認 API 已啟用、Key 限制、Billing 和 Quota。Azure：確認資源／訂閱有效、Region、網路限制及方案額度。DeepL：確認 API Key 與 API Endpoint 的方案一致。

完成後應看到：修正實際原因後再測一次，不必一次更改所有設定。

如果不同／先別做：403 並不一定是付款問題。不要只因看到這個代碼就升級方案或移除所有安全限制。只看與本頁 Provider 對應的項目。

故障排除 · 太頻繁／429、方案額度

Step 26 · 暫停請求

你現在在哪裡：429 通常表示流量／配額限制；Azure 額度錯誤或 DeepL 456 也要查看方案用量。

請這樣做：等候後手動重試，或明確將 Reply 改成本機。到本頁 Quota 章節檢查官方限制，別增加重試頻率。

完成後應看到：若選了本機備援，結果會清楚標示；永久引擎不會因此自動改變。

如果不同／先別做：額度限制時可在提示中暫用本機、另一家已設定服務或暫停；未設定服務需先完成獨立設定和同意。不能繼續送往被鎖服務，也不改寫永久引擎。

停用 · 先停止新的雲端請求

Step 27 · 只停用 Babelander 的此服務

你現在在哪裡：在 DeepL 設定視窗。

請這樣做：按「停用此服務」。使用此服務的功能會暫停；Key 暫時保留，重新使用須再次確認。

完成後應看到：後續不再使用此服務；取消中的結果不會複製。

如果不同／先別做：已經傳出去的內容不能撤回。停用本機程式不等於關閉官方服務或取消方案。

刪除或更換 Key（Rotate）

Step 28 · 先清除本機 Key

你現在在哪裡：在 DeepL 設定視窗。

請這樣做：按「刪除本機 Key」。

完成後應看到：加密 Key 副本被刪除，用量紀錄仍保留。

如果不同／先別做：如果 Key 外洩，還要完成下面的官方撤銷；只刪本機不能讓別人手中的 Key 失效。

Step 29 · 在官方撤銷或更換

你現在在哪裡：DeepL 的官方帳戶管理頁。

請這樣做：在 DeepL Account → API Keys & Limits，舊 Key 旁更多選項 → Deactivate key／停用金鑰，再確認。若要更換，可先建立新 Key、更新程式並測試，再撤銷舊 Key；外洩時優先撤銷。

完成後應看到：舊 Key 不再能呼叫服務；新 Key 若需要使用，回 Babelander 儲存並測試。

如果不同／先別做：已停用的 Key 通常不能恢復。撤銷 Key 不等於取消 API 方案；停止訂閱需在方案／Billing 頁另行處理。

隱私：聊天室固定本機，各功能獨立選擇

只有明確選用 DeepL API 的功能會傳送待翻譯文字。字幕傳送框選 OCR 文字；裝備／任務傳送規則未能完成的文字；Reply 傳送當前主動提交的中文。圖片、聊天室來訊、歷史與完整詞庫不會上傳。儲存 Key 本身不會啟用任何雲端功能。Key 使用 Windows 使用者加密；搬到另一台電腦或帳號需要重新輸入。設定、儲存或測試服務不會自動改變功能引擎。

1. 30 秒快速開始

① 框選到「即時翻譯」按 ① 框選原文，框住遊戲字幕。
② 開始按 ② 開始翻譯，再切回遊戲。
③ 看譯文繁體中文會顯示在遊戲浮層。
④ 暫停再次按開始按鈕，或用 Ctrl+Alt+F2。
第一次使用本機翻譯？
到「設定與下載」下載翻譯模型與額外執行元件。若已設定 Google / Azure / DeepL，雲端功能不必先下載或暖機本機翻譯模型。

2. 下載、安裝與第一次啟動

一般使用者：建議安裝版

到官方 Release 頁下載檔名以 -Setup.exe 結尾的安裝檔。
執行安裝程式，閱讀授權條款後完成安裝。
第一次開啟 Babelander，等待啟動自檢完成。
要用本機翻譯時，到「設定與下載」下載模型與 Runtime；要用雲端時，設定對應 API。

官方最新版本下載頁

免安裝版

下載 Windows-Lite.zip，完整解壓縮後再啟動 Babelander.exe。不要直接在 ZIP 裡執行。

本機模型不是安裝包內建。
本機翻譯模型與 llama.cpp / CUDA Runtime 需要由你在程式內主動下載。

2-1. Windows 版本需求

Windows 太舊會無法正常使用 Babelander。
Babelander 目前最低支援 Windows 10 版本 2004（Build 19041） 或更新版本；Windows 11 可直接使用。

如果 Windows 版本低於 Build 19041，可能會遇到以下情況：

  • 安裝程式直接拒絕安裝。
  • 字幕／聊天浮層無法使用 Windows 的「擷取排除」功能。
  • Overlay 可能被 OCR 再次讀到，造成重複辨識或畫面異常。
  • 部分視窗與 DPI 行為可能不符合 Babelander 的支援環境。

怎麼查看自己的 Windows 版本？

按 Win + R。
輸入 winver 後按 Enter。
查看「版本」與「OS 組建」。OS 組建需為 19041 或更高。
如果版本太舊，請先透過 Windows Update 升級系統，再安裝 Babelander。若電腦無法升級到 Windows 10 Build 19041 以上，建議不要使用 Babelander。

4. 字幕即時翻譯

讓遊戲字幕或對話文字出現在畫面上。
切到「即時翻譯」→ 按 ① 框選原文。
只框住會出現英文字幕的區域，避免大量無關圖像。
按 ② 開始翻譯。文字穩定且有變化時才重新 OCR 與翻譯。

字幕浮層

  • 背景模式：半透明黑底 / 透明背景。
  • 黑底深度：調整背景遮罩強度。
  • 中文字級：12～60。
  • 鎖定位置並讓滑鼠穿透：勾選後不擋遊戲滑鼠；取消勾選可拖曳字幕。
  • 字幕移回原文區域：把浮層恢復到原本框選位置。
建議 Windows 10 2004（Build 19041）以上或 Windows 11。視窗化／無邊框遊戲通常比獨佔全螢幕更穩定。

5. 裝備卡翻譯

裝備卡是「一次性翻譯」：每次框選、放開滑鼠後處理一次。

到「裝備與任務」確認 啟用裝備卡。
按 框選並翻譯裝備卡，或用預設 Alt+T。
盡量完整框住整張裝備資訊卡。
放開滑鼠後等待結果；可保留原文顏色、數值與屬性結構。
裝備卡會先跑本機詞典、規則與數值結構解析；選雲端時，能在本機完成的內容不必全部送雲端。

6. 任務卡翻譯

到「裝備與任務」確認 啟用任務卡。
按 框選並翻譯任務卡。
框住完整任務標題、描述、目標與進度。
放開滑鼠，等待任務卡翻譯完成。

任務卡預設沒有全域快捷鍵；可以自行設定，也可以只用按鈕。框選時按 Esc 可取消。

7. 聊天翻譯

到「聊天翻譯」按 ① 框選聊天區。
框住聊天訊息本體，可含時間、頻道與玩家名稱；避開上方分頁與下方輸入框。
按 ② 開始監測。
有新訊息時浮層會加入譯文；隱藏面板後仍可繼續監測。
  • 跟隨框選時的視窗：遊戲視窗移動或等比例縮放時跟著調整。
  • 啟用花邊背景：切換聊天裝飾。
  • 以目前畫面重新定位：大量捲動或位置判斷失準時使用。
聊天來訊固定本機處理。若跟隨的遊戲視窗被最小化、遮住、關閉、移出螢幕或縮得太小，擷取可能暫停。

8. 中文 → 英文回覆

回覆工具和聊天監測分開，不需要先啟動聊天監測。

在「聊天翻譯」按 中文 → 英文回覆。
輸入中文，最多 300 字。
按 Enter 或「翻譯並複製」；換行用 Shift+Enter。
通過檢查後會自動複製；若有疑義，先核對再按「複製英文」。
切回遊戲自行 Ctrl+V 貼上並送出。
Babelander 不會自動切換遊戲、不會自動貼上，也不會自動送出聊天訊息。

9. 本機 / Google / Azure / DeepL 怎麼選

方式優點注意
本機下載模型後可離線；聊天來訊固定本機。需要模型與 Runtime，首次使用會暖機並占用 RAM / VRAM。
Google不用啟動本機翻譯模型，可按功能指定。需要自己的 API，可能產生費用或遇到額度限制。
Azure不用本機模型，可與其他服務分工。需要 Azure Translator 設定；有本地安全額度控制。
DeepL可作為字幕、卡片、回覆引擎。需 DeepL API；方案與計費週期依帳號而異。
  • 字幕、裝備、任務、中文 → 英文回覆可各自選服務。
  • 聊天室來訊固定本機。
  • 儲存 API Key、測試成功，不代表已切換到該服務。
  • 額度不足時可暫用其他已設定服務、本機，或暫停該功能；不改永久設定。

繁中設定教學：Google · Azure · DeepL

10. 自訂辭典

可以固定人名、術語、技能、裝備名稱與整句譯文。支援「共用、裝備、任務、字幕、聊天」模式範圍，也可指定遊戲。

支援新增、編輯、刪除、匯入 CSV／ZIP、匯出自訂 CSV。遊戲專用設定優先於通用設定。

11. 歷史與測試

貼上一段英文 → 按「翻譯這段文字」→ 檢查譯文、來源與耗時。若術語不滿意，再到自訂辭典調整。

手動測試時會暫停畫面監看，避免與遊戲 OCR 同時互相干擾。

13. 效能與模型

一般啟動只做環境自檢，本機翻譯模型在真正有功能需要本機推論時才暖機。停止所有需要本機模型的工作後，會依設定延遲釋放；目前預設約 5 分鐘。

「設定與下載」可調整效能模式、翻譯 CPU 執行緒、畫面檢查間隔、文字穩定等待、保留近期前文等。

不知道怎麼設時先用預設值。追求速度前，先確認不會讓遊戲本身掉幀。

14. 常見問題排除

狀況先這樣檢查
字幕完全沒反應確認已框選、已開始；再看「辨識原文」是否有 OCR 結果。
字幕一直是舊的按「重翻目前對話」；若位置變了就重新框選。
OCR 認錯縮小框選範圍、提高遊戲文字清晰度、避免動畫與半透明特效。
翻譯很慢確認本機 / 雲端來源；本機首次暖機較久，CPU / GPU 滿載也會拖慢。
Alt+T 沒反應確認裝備卡啟用、快捷鍵狀態為已啟用；被其他程式占用時改鍵或用按鈕。
聊天沒有新訊息確認框選不含輸入框；大量捲動後按「以目前畫面重新定位」。
雲端服務選不到先完成該 Provider 憑證與同意設定；不可用或額度鎖定時不會出現在可選清單。
雲端額度滿依提示暫用本機 / 其他服務，或暫停該功能。
模型顯示 COLDCOLD 代表尚未需要模型；真正啟用本機工作時才暖機，是正常設計。
遊戲全螢幕看不到浮層優先改用視窗化或無邊框視窗模式。

15. 更新、備份與解除安裝

更新不用先解除安裝：關閉 Babelander 後直接執行新版 Setup，可保留既有模型與設定。

解除安裝會刪除 Babelander 管理的模型、Runtime、設定、自訂辭典、Key、用量與快取。要保留的資料請先備份。

解除安裝不會替你撤銷 Google / Azure / DeepL API Key，也不會取消第三方服務訂閱。

16. 隱私與雲端文字傳送

  • 本機翻譯不需要把待翻譯文字送到第三方翻譯服務。
  • 聊天室來訊固定本機。
  • 字幕、裝備、任務、中文回覆選 Google / Azure / DeepL 時，必要文字會傳送到你選擇的第三方服務。
  • 首次切換相關雲端功能時會顯示文字傳送同意。
  • API 服務的資料政策、計費與保留規則以各服務商條款為準。

17. FAQ

Q：一定要下載本機模型嗎？

不用。字幕、裝備、任務、中文回覆若使用雲端，可以不先暖機本機模型；但聊天來訊固定本機，所以要用聊天翻譯仍需本機模型。

Q：設定雲端後會自動改用雲端嗎？

不會。設定憑證和「這個功能選哪個 Provider」是分開的。

Q：卡片翻譯和字幕翻譯差在哪？

字幕是持續監看；裝備與任務卡每框一次只翻一次，適合靜態資訊面板。

Q：可以自動貼英文並送出嗎？

目前不會。Babelander 只翻譯與複製，貼上與送出由你自己操作。
